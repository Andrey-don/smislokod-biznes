# Скилл: business-review

**Триггер:** `/business-review`
**Назначение:** Поддерживать `business/` живым — цикл пополнения мозга бизнеса.
**Когда запускать:** Раз в неделю / после значимого события / после эфира или звонка.

---

## Принцип: мозг растёт, пока в него докладывают

**Цикл, который работает:**

1. **В течение недели** — скидываешь голосом «по горячему» в notes:
   вопросы, возражения, идеи — всё что услышал, узнал, заметил.

2. **В конце недели** — один промт:
   «вот накопленное, разбери и обнови файлы в business/».
   Claude сам найдёт, куда положить.

3. **После значимого события** (запуск, провал, фидбек, эфир) —
   «проанализируй вопросы из чата эфира и обнови `audience/objections.md`, `audience/avatar.md`».

**Главное правило:** валидируй своей головой.
Иначе ИИ будет запихивать ерунду наравне с золотом.
Лень валидировать — получишь мусор.

---

## Промт 1 — Разбор лендинга (если есть готовый)

> Если уже есть рабочий лендинг — не пиши контент в `business/` с нуля.
> Запусти этот промт, и Claude разложит всё сам.

```
У меня уже есть рабочий лендинг по адресу [ВСТАВЬ URL ИЛИ ПУТЬ К index.html].

Действуй так:
1. Открой лендинг (через WebFetch или Read локального файла).
2. Прочитай его целиком — hero, услуги, оффер, цены, отзывы, FAQ.
3. Вытащи ключевые смыслы и разложи по папкам business/:
   - продукт, тарифы, цены → products/
   - аудитория, боли, путь → audience/
   - оффер, копи-банк, формулировки → assets/copy-bank.md
   - конкурентные преимущества → marketing/competitors.md
4. После каждой папки покажи мне краткий отчёт: что нашёл и куда положил.
5. Не выдумывай данные — если на лендинге чего-то нет, оставь файл
   с пометкой «заполнить интервью-промтом».

Всегда отвечай на русском.
```

---

## Промт 2 — Разбор зум-звонка / встречи / эфира

> Транскрипция совещания, эфира или продающего звонка лежит в файле —
> вытаскиваем смысл одним промтом.

```
У меня лежит транскрипция встречи в файле [путь к файлу].

Действуй так:
1. Прочитай транскрипцию целиком.
2. Вытащи 5-7 ключевых идей, решений или инсайтов.
3. По каждой идее определи, куда она относится:
   - идея про аудиторию → business/audience/
   - решение по продукту → business/products/
   - принцип ведения переговоров → ai-clone/principles/business.md
   - выученный урок → ai-clone/feedback/
4. Покажи мне предложения: «вот эту идею предлагаю положить сюда» —
   я подтверждаю или меняю.
5. После подтверждения — запиши в нужные файлы.

Всегда отвечай на русском.
```

---

## Промт 3 — Разбор накопленных заметок (конец недели)

```
Вот мои заметки за неделю:
[ВСТАВЬ ТЕКСТ ИЗ NOTES — голосовые расшифровки, идеи, вопросы клиентов]

Действуй так:
1. Прочитай всё.
2. Разбей на смысловые блоки: аудитория / продукт / маркетинг / идеи / возражения.
3. По каждому блоку предложи: «это предлагаю добавить в [файл]» — я подтверждаю.
4. После подтверждения — запиши. Не выдумывай, не додумывай.

Всегда отвечай на русском.
```

---

## Когда что запускать

| Ситуация | Промт |
|---|---|
| Есть готовый лендинг | Промт 1 — разбор лендинга |
| Был зум, созвон, эфир | Промт 2 — разбор транскрипции |
| Конец недели, накопились заметки | Промт 3 — разбор notes |
| Ежемесячная сверка | Проверь даты в файлах, обнови устаревшее |
