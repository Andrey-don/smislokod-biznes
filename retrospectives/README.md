# retrospectives/ — рефлексия после каждой сессии

Рефлексия после каждой важной рабочей сессии. Не «что я сделал», а «что выучил и как применю».

## Формат имени файла

`YYYY-MM-DD_HH-MM_краткое-описание.md`

Примеры:
- `2026-05-14_14-30_настройка-hooks.md`
- `2026-05-20_10-00_заполнение-business-через-интервью.md`

## Когда писать

- После завершения крупной задачи (больше часа работы).
- После каждого дня активной работы с проектом.
- После любой нетривиальной ошибки — чтобы зафиксировать, что выучили.

## Шаблон

Используй файл `TEMPLATE.md` в этой папке.

## Связь с ai-clone/feedback/

Если в рефлексии появляется новое правило («больше так не делать», «всегда делать вот так») — оформи его как файл в `ai-clone/feedback/` по формату Rule → Why → How to apply. Claude сам предложит это в конце сессии, если CLAUDE.md настроен правильно.
