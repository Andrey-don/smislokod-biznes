# Описание: Инструкция спланируй свой проект.html

**Тип:** Пошаговая инструкция (сохранённая веб-страница с платформы СмыслоКод)
**Курс:** Практикум май 2026 / День 2 — Метод эффективной работы
**Объём:** ~3 часа работы

## Суть документа

Главный операционный документ всего проекта. Содержит 11 этапов создания шаблонного вайб-проекта: от настройки безопасности до автоматических триггеров. Большую часть работы выполняет Claude Code — человек управляет голосом.

## Структура (11 этапов)

| Этап | Что делаем | Время |
|------|-----------|-------|
| 1 | Звук (hooks), безопасность (settings.json), авто-память | ~30 мин |
| 2 | AI-Clone — цифровая проекция себя через голосовое интервью | ~45 мин |
| 3 | Mastery — чужие методологии великих (личный совет директоров) | ~30 мин |
| 4 | Business — второй мозг бизнеса (products, audience, economics...) | ~60-90 мин |
| 5 | CLAUDE.md + plans/ + retrospectives/ | ~30 мин |
| 6 | Контекст-инжиниринг — как ИИ выбирает нужный контекст | ~20 мин |
| 7 | Промтинг: 6 шагов вайб-кодинга, «10 причин обосраться», модели | ~30 мин |
| 8 | Скиллы Claude Code (bulletproof, Frontend Design, Whisper и др.) | ~30 мин |
| 9 | MCP, плагины, CLI — подключение внешнего мира | ~15 мин |
| 10 | Браузерный Claude (Claude Chrome Extension) | ~10 мин |
| 11 | Триггеры — агент работает 24/7 по расписанию | ~20 мин |

## Итоговая структура проекта (что получится)

```
ваш-проект/
├── CLAUDE.md             ← правила, навигация (≤200 строк)
├── .claude/              ← настройки агента
│   ├── settings.json     ← доступы, запреты, режимы
│   ├── skills/           ← команда экспертов
│   └── agents/           ← субагенты
├── ai-clone/             ← цифровая проекция владельца
│   ├── identity/         ← ценности, биография
│   ├── voice/            ← тон, словарь
│   ├── thinking/         ← ментальные модели
│   ├── principles/       ← правила продукта/кода/бизнеса
│   ├── feedback/         ← правила через ошибки
│   ├── mastery/          ← методологии великих
│   └── reference/        ← инфра без секретов
├── business/             ← второй мозг бизнеса
│   ├── products/         ← что продаём, тарифы
│   ├── audience/         ← аватары, боли, путь клиента
│   ├── economics/        ← юнит-экономика, выручка
│   ├── marketing/        ← каналы, воронка
│   ├── goals/            ← KPI, годовые/кв. цели
│   ├── assets/           ← бренд-гайдлайны, копи-банк
│   └── life-metrics.md   ← LIVE-маркеры для живых цифр
├── plans/                ← технические планы (1 план = 1 функция)
└── retrospectives/       ← рефлексии после каждой сессии
```

## Ключевые принципы

- **Ничего руками** — только через Claude Code (голосом)
- **1 задача = 1 диалог** — не засорять контекст
- **CLAUDE.md ≤ 200 строк** — всё лишнее в отдельные файлы
- **plans/ vs Plan Mode** — Plans/ живёт вечно, Plan Mode забывается после закрытия
- **Контекст ≤ 60%** — при 70%+ агент деградирует
- **Bulletproof** перед каждой крупной фичей

## Как использовать

Открывать этапы по одному, раскрывать, выполнять, сворачивать. Промты готовы — копируй и вставляй. В конце каждого этапа есть блок «если не получилось».
