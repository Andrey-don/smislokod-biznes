## Ключевые схемы

**Анатомия проекта** (карта файловой структуры):
```
ваш-проект/
├── CLAUDE.md          правила, навигация
├── .claude/           настройки агента
│   ├── settings.json
│   ├── skills/        команда экспертов
│   └── agents/        субагенты
├── ai-clone/          вы лично
├── business/          ваш бизнес
├── plans/             фичи по фазам
└── retrospectives/    рефлексия

~/.claude/memory/      авто-память (глобально)
```

**Цикл вайб-кодинга** (6 шагов):
```
Ваша задача → Селектор контекста → 6 шагов методологии
→ Skills + агенты + MCP → Готово + git commit → Триггер в 7:00
```

**Разница подходов:**
| Без системы | С AI-Clone + Business + Mastery |
|------------|--------------------------------|
| 15 итераций | 2 итерации |
| Час на задачу | 10 минут |
| Объясняешь себя заново | Контекст подгружается сам |
| Генерический результат | Продукт уровня студии |

**Мозг проекта — 5 частей + git:**
- `CLAUDE.md` — правила и навигация
- `ai-clone/ + business/` — второй мозг
- `plans/` — технические планы
- `retrospectives/` — рефлексия
- `live-metrics.md` — живые цифры (маркер LIVE)
- `git` — машина времени

**CLAUDE.md — 5 блоков:**
1. Описание проекта (2-3 предложения)
2. Технологический стек
3. Структура файлов
4. Правила и стиль
5. Роутинг на файлы

**6 правил CLAUDE.md:**
1. До 200 строк (детали — в business/ и .claude/rules/)
2. Заканчивай отчётом по каждому диалогу
3. Коммит после задачи (git = машина времени)
4. Всегда Bulletproof при постановке фичи
5. Сверяйся с business/ (avatar.md, brand-guidelines.md)
6. Безопасность — запрещай в settings.json

## Как использовать

Смотреть как визуальный ориентир и шпаргалку. Сначала — чтобы понять общую картину. В процессе работы — чтобы быстро вспомнить структуру или правило.
