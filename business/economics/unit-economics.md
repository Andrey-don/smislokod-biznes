## Ключевые метрики

| Метрика | Значение | Формула |
|---|---|---|
| **LTV** (lifetime value) | <!-- ₽ --> | Средний чек × Кол-во покупок × Срок жизни |
| **CAC** (стоимость привлечения) | <!-- ₽ --> | Рекламный бюджет / Кол-во клиентов |
| **LTV/CAC** | <!-- x --> | LTV ÷ CAC (норма: >3) |
| **Маржа** | <!-- % --> | (Выручка − Себестоимость) / Выручка |
| **ARPU** (средний чек) | <!-- ₽ --> | Выручка / Кол-во клиентов |
| **Churn** (отток) | <!-- % --> | Ушедшие / Всего клиентов за период |
| **Payback period** | <!-- дней --> | CAC / (LTV / Срок жизни в днях) |
