# raw/ — Исходники

Сюда кладём необработанные материалы:

- Транскрипции Zoom-звонков с клиентами
- Переписки (копии важных диалогов)
- Интервью с аудиторией
- Записи созвонов с командой
- Голосовые расшифровки

## Важно

**Эта папка НЕ коммитится в git** — в `.gitignore` прописано `business/raw/`.

Причина: здесь могут быть персональные данные клиентов (имена, телефоны, контекст переговоров).
Храни локально, не публикуй.
