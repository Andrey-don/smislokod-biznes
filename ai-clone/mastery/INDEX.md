# Mastery — личный совет директоров

Концентрат методов лучших умов мира по нужным областям.

## Чем отличается от Skills

- **Skills** — упакованный промт для выполнения задачи (как делать)
- **Mastery** — точка зрения эксперта на целую область (как думать)

## Принцип сборки

У каждого великого автора 1-3 гениальных метода. Не пересказ книги —
только конкретный приём с алгоритмом: что / как / когда применять.

## Структура

Одна папка = одна область. Один файл = один автор.
