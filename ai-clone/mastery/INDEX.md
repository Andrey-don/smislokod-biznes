# Mastery — личный совет директоров

Концентрат методов лучших умов мира по нужным областям.

## Чем отличается от Skills

- **Skills** — упакованный промт для выполнения задачи (как делать)
- **Mastery** — точка зрения эксперта на целую область (как думать)

## Принцип сборки

У каждого великого автора 1-3 гениальных метода. Не пересказ книги —
только конкретный приём с алгоритмом: что / как / когда применять.

## Структура

Одна папка = одна область. Один файл = один автор.

## Как вызывать mastery в работе

Не нужно объяснять Claude какую область использовать — он сам выбирает по задаче.
Но можно указать явно, если нужна конкретная линза.

**Кейс 1 — контент-завод.**
Говоришь: «напиши пост в канал про X».
Claude сам идёт в `mastery/copywriting/`, берёт методы Огилви (заголовок),
Шугермана (скользкая горка), накладывает твой голос из `ai-clone/voice/` —
и пишет так, как написал бы ты, с конкретной техникой. Не универсальный пост, а пост через линзу мастера.

**Кейс 2 — финансовый анализ.**
Спрашиваешь: «что у нас по цифрам в этом квартале?»
Claude берёт `mastery/financial-analysis/`, идёт в `business/economics/`,
смотрит цели из `business/goals/quarterly.md`, применяет методы к данным.
Возвращает не «просели заявки», а «юнит-экономика дрейфует, поднимай LTV».

**Кейс 3 — переговоры.**
Перед звонком с клиентом: «помоги подготовиться к переговорам о цене».
Claude берёт `mastery/negotiations/` (метод Восса), анализирует контекст из `business/`,
даёт конкретный сценарий с формулировками.

**Промты для явного вызова:**
```
Используй методы из mastery/copywriting/ и мой голос из ai-clone/voice/,
напиши пост про [тему].

Посмотри на ситуацию через линзу mastery/decision-making/ и предложи
три варианта решения с плюсами и минусами каждого.
```
