# Джон Кэплз — Копирайтинг

**Кто:** Вице-президент BBDO, автор «Tested Advertising Methods». Первым начал систематически тестировать рекламные заголовки на реальных данных. Написал один из самых знаменитых заголовков в истории рекламы: «They laughed when I sat down at the piano...»

---

## Метод 1: Тестирование заголовков (A/B до A/B)

**Суть:** Кэплз доказал, что заголовок может увеличить отклик на 1900%. Один и тот же продукт, разный заголовок = разный результат. Никогда не угадаешь — только тест покажет.

**Шаги:**
1. Напиши минимум 5-10 вариантов заголовка перед выбором одного
2. Для каждого определи гипотезу: почему этот должен работать
3. Тестируй один элемент за раз — только заголовок, не заголовок + картинку
4. Победитель тестируй против нового претендента — постоянный процесс
5. Храни все заголовки и результаты: банк данных ценнее любой теории

**4 типа заголовков по Кэплзу (в порядке эффективности):**
1. **Выгода:** «Как я улучшил свою память за одну ночь»
2. **Новость:** «Наконец-то метод похудения, который работает в пожилом возрасте»
3. **Любопытство:** «Они смеялись, когда я сел за пианино...»
4. **Быстрый/лёгкий результат:** «За 15 минут — без усилий»

**Когда применять:** Перед финальным выбором заголовка для любого важного текста.

## Метод 2: Формула «До / После / Мост»

**Суть:** Самая универсальная формула продающего текста. Работает для поста, лендинга, письма, оффера.

**Шаги:**
1. **ДО** — опиши мир читателя сейчас: боль, проблема, ситуация (2-3 предложения)
2. **ПОСЛЕ** — опиши мир, в котором проблемы нет: желаемый результат (2-3 предложения)
3. **МОСТ** — объясни, как твой продукт/услуга переводит из «до» в «после»

**Шаблон:**
```
ДО: Представь: ты каждый раз садишься писать пост и смотришь в пустой экран...

ПОСЛЕ: А теперь — каждое утро 15 минут, и готовый пост, который люди сохраняют и пересылают.

МОСТ: Именно для этого я создал [продукт] — он делает X, чтобы ты получил Y.
```

**Когда применять:** Любой оффер, любая точка входа в воронку.

## Метод 3: Заголовок через результат читателя

**Суть:** Кэплз обнаружил, что заголовки с результатом от первого лица читателя работают в разы лучше, чем заголовки про продукт.

**Шаги:**
1. Замени «наш продукт делает X» на «вы получаете X»
2. Сделай заголовок о читателе, не о продукте
3. Укажи конкретный, измеримый результат
4. Добавь временной маркер если возможно: «за 30 дней», «к пятнице»

**Примеры трансформации:**
- ❌ «Наши курсы по копирайтингу — лучшие на рынке»
- ✅ «Как я начал зарабатывать на текстах через 3 недели после первого урока»

**Когда применять:** Заголовки лендингов, постов, email-тем.
