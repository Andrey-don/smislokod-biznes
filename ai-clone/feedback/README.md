# Feedback — правила через ошибки

Эта папка **не заполняется вручную**. Она растёт естественно в процессе работы.

## Как работает

1. Claude предложил что-то не так
2. Ты говоришь: «не так, потому что X»
3. Добавляешь: «запиши правилом в ai-clone/feedback/»
4. Claude создаёт файл с тремя секциями
5. В следующем диалоге — уже не делает эту ошибку

## Формат каждого файла

```
# Название правила

## Правило
Чёткая формулировка: что делать / не делать.

## Почему
Причина — контекст, из-за которого правило появилось.

## Как применить
Когда именно это правило срабатывает, в каких ситуациях.
```

## Примеры файлов

- `no-em-dashes.md` — не использовать тире в постах
- `always-confirm-delete.md` — всегда спрашивать перед удалением
- `russian-only.md` — отвечать только на русском
