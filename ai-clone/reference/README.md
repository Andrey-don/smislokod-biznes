# Reference — инструменты и инфраструктура

Технические детали без секретов: ссылки на инфраструктуру, инструменты,
сервисы. Никаких паролей, API-ключей и токенов.

## Что сюда класть

- Адреса серверов, доменов, окружений (без паролей)
- Инструменты, которыми пользуюсь с кратким описанием
- Ссылки на репозитории, деплой-среды
- Схемы инфраструктуры

## Что НЕ класть

- Пароли, API-ключи, токены → в `.env` локально, не в git
- Персональные данные клиентов
